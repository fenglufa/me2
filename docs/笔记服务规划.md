# 4. 关键使用流程（Flow）

---

## ⭐ 流程 A：用户写一条简单笔记

1. 用户输入：“今天心情很混乱。”
2. 用户点击保存
3. AI 判定：

   * 类型：emotion
   * 情绪：sad 0.82
4. 存储结构化
5. 分身系统收到事件：

   * “用户今日情绪低落”
   * 分身更新：状态→忧郁
6. 分身写今日日记：

   ```
   今天我感受到你有些不安，我也跟着安静了下来。
   ```
7. 用户打开 Tab3（分身日记）看到反馈内容

---

## ⭐ 流程 B：用户记账

输入：「午饭 35 咖啡 20」

AI 识别：

* 两条账单
* 自动归类食物/饮品
* 自动统计每日消费
* 可在洞察页面看到趋势

—

## ⭐ 流程 C：用户写 TODO

输入：「明天买牛奶」

AI：

* 设置为 todo
* 自动提醒（可选）
* 进入 todo 列表

分身行为：

* 分身可能会说：“记得明天要买牛奶哦。”

---

## ⭐ 流程 D：笔记影响分身情绪与故事

输入：「我今天通过了面试！」

AI：

* 类型：事件 + emotion（happy）

分身：

* 记为“好消息”，写祝福日记
* 动画状态变 → 开心
* 生成一个“今日愉快事件”
